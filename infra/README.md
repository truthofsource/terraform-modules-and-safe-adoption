# Actual modules, public composition

The network and storage modules are copied from the actual implementation with neutral labels. The root is a new default-Off composition for two fictional environments and uses mocked providers for tests. Existing environment roots/state are not merged by this example.

The storage module includes private/keyless defaults, diagnostics and explicit group-role inputs. The network module includes integration delegation and endpoint capacity. Module reuse does not grant privileges or create a private endpoint by itself.

Never apply this composition to the live state or remove adoption references based on a passing mock test. The real moved declarations and address map are explanatory files outside this root.
